# University Works

## 🇷🇺 Описание (Русский)

Этот репозиторий содержит учебные работы, выполненные в рамках обучения в **СПБГЭТУ «ЛЭТИ»**.  
Факультет **КТИ** (Компьютерных технологий и информатики).  
Направление подготовки **ПМИ** (Прикладная математика и информатика).

Репозиторий предназначен для хранения и систематизации лабораторных и практических работ по различным дисциплинам, изучаемым в ходе обучения.

### 📁 Структура репозитория
```
university-works/
│
├── Computer Science/
│   ├── 1 Semester/
│   │   └── Laboratory work _/
│   │       ├── Job_condition.md
│   │       └── src/
│   │
│   └── 2 Semester/
│       └── Laboratory work _/
│           ├── Job_condition.md
│           └── src/
│
└── Programming/
    ├── Coursework/
    ├── 1 Semester/
    │   └── Laboratory work _/
    │       ├── Job_condition.md
    │       └── src/
    │
    └── 2 Semester/
        └── Laboratory work _/
            ├── Job_condition.md
            └── src/
```

### 📄 Описание содержимого

- **Computer Science (Информатика)** — лабораторные и практические работы по информатики  
- **Programming (Программирование)** — лабораторные работы по программированию  
- **Job_condition.md** — файл с описанием задания и условиями выполнения лабораторной работы  
- **src/** — исходный код решения лабораторной работы
